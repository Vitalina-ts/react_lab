# Інтерактивний світлофор — лабораторна робота №2

Проєкт використовує React, JavaScript (JSX) і звичайний CSS.

- `App` відображає один `TrafficLights`.
- `TrafficLights` зберігає активний сигнал, лічильники та орієнтацію в трьох `useState`.
- `Light` отримує колір, активність і `onSelect` через props та повідомляє батьківський компонент про вибір.
- `StatsBar` показує статистику, активний сигнал і кнопку орієнтації. Власного стану не має.

Спочатку активний червоний сигнал, усі лічильники дорівнюють нулю. Кожне натискання, включно з повторним, збільшує відповідний лічильник. Загальна кількість обчислюється як сума лічильників. Перемикання орієнтації зберігає сигнал і статистику.

## Команди

- `npm run dev` — запуск розробки.
- `npm run build` — збірка.
- `npm run lint` — перевірка коду.
- `npm run preview` — перегляд збірки.

`jsconfig.json` налаштовує підтримку JavaScript/JSX у редакторі. TypeScript для проєкту не потрібний.
